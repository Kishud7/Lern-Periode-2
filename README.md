## Zusammenfassung des Codes:

Eingabe:
Der Benutzer gibt die X- und Z-Koordinaten sowie die Blickwinkel von zwei verschiedenen Positionen in Minecraft ein.

Winkel umrechnen:
Die eingegebenen Winkel werden in Radiant umgerechnet, damit das Programm damit rechnen kann. Blickrichtungen berechnen: Mithilfe von mathematischen Funktionen wie Math.Sin() und Math.Cos() werden die Blickrichtungen berechnet.

Stronghold-Koordinaten berechnen:
Das Programm berechnet den Schnittpunkt der beiden Blickrichtungen und ermittelt daraus die ungefähre Position des Strongholds.

Fehler überprüfen:
Falls die Blickrichtungen keinen gültigen Schnittpunkt ergeben, zeigt das Programm eine Fehlermeldung an.

Ergebnis anzeigen:
Die berechneten X- und Z-Koordinaten sowie die Entfernung zum Stronghold werden angezeigt.
